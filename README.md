# Home TV, canale di prova

Questo ramo serve solo a chi prova la versione nuova sul proprio TV. In TizenBrew si aggiunge il modulo GitHub
**btc4fun/tv-sito@prova** e lo si mette all'avvio automatico. Per tornare alla versione di tutti si rimette all'avvio
**btc4fun/tv-sito**. Le pagine stanno in https://btc4fun.github.io/tv-sito/prova/.
